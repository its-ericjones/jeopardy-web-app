# Facilitator Guide

## Purpose

This guide is for the person preparing and running a game session. It focuses on the files you should save, the answer key you should keep nearby, and the best sequence for running the game smoothly.

## Recommended Preparation Workflow

1. Open `jeopardy.html`.
2. Click `Create`.
3. Fill out the game title, categories, clues, responses, and teams.
4. Click `Export Draft` periodically while writing.
5. When the game is complete, click `Export Game`.
6. Allow the game file download.
7. Click `Open Answer Key`.
8. In the print dialog, save the answer key as a PDF or print it.
9. Click `Create` when you are ready to start the playable board.

This produces two facilitator-ready artifacts:

- A reusable complete game file, such as `2000s-pop-culture.txt`.
- A printable answer key PDF, usually named from the game title.

## What To Save

Save these files together when preparing a game:

- Complete game `.txt` file
- Answer key PDF
- Any draft files you want to preserve

Keeping the game file and answer key in the same folder makes it easier to reuse the game later.

## Drafts Versus Complete Game Files

Use a draft file while writing. Draft files can be incomplete and may include empty categories, clues, responses, or team names.

Use a complete game file when playing. Complete game files should include:

- A title
- 5 categories
- 5 clues per category
- A clue and response for every point value

## Answer Key Use

The answer key is designed for the facilitator, not the players. It includes:

- Game title
- Facilitator answer key label
- Generated date
- Category names
- Point values
- Clues
- Correct responses

The point values do not include dollar signs so the PDF stays visually simple and matches the current app decision.

## Running The Game

Before players arrive:

1. Open the app.
2. Use `Play` to load the complete game file, or use `Create` if the game is already filled out in the form.
3. Add or confirm teams.
4. Keep the answer key PDF open or printed.

During the game:

1. Let a team choose a category and point value.
2. Click that cell.
3. Read the clue.
4. Click `Show Answer` after the team responds.
5. Award or subtract points.

The app marks the cell as used after scoring through the clue modal.

## Session Recovery

The app saves some state in the browser. If the browser is refreshed during a session, the board, used cells, title, teams, and scores may restore automatically.

Use `Reset Board` only when you are ready to clear the current session.

## Facilitator Checklist

Before the session:

- Confirm the game file loads with `Play`.
- Confirm all teams can be added.
- Export or print the answer key.
- Verify the answer key is not blank.
- Confirm the PDF or printed answer key includes all categories.

After the session:

- Save the reusable game file if you changed anything before play.
- Keep the answer key with the game file if the game will be reused.
- Use `Reset Board` when you no longer need the current browser state.
